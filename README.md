# 🥗 NutriAção — Projeto Integrador (1º Período ADS)

Sistema de gestão para refeitório corporativo integrado a um banco de alimentos, conectando funcionários (confirmação antecipada de presença no almoço para redução de desperdício) e instituições parceiras (cadastro de ONGs).

> **Curso:** Análise e Desenvolvimento de Sistemas (ADS) — 1º Período (Manhã)  
> **Instituição:** Faculdade Católica Imaculada Conceição do Recife (FICR)

## 💻 Telas do MVP (Front-End)

* **Cadastro de Instituição Parceira (`cadastro.html`):** Formulário responsivo para registro de ONGs interessadas em receber excedentes alimentares (CNPJ, nome e e-mail).
* **Painel do Funcionário (`funcionario.html`):** Interface *mobile-first* com interruptor interativo (RSVP) para confirmação de almoço até às 10:00 e visualização do cardápio diário.
