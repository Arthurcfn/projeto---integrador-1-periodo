# NutriAção — Projeto Integrador (1º Período ADS)

Sistema de gestão para refeitório corporativo integrado a um banco de alimentos, conectando empresas doadoras a instituições parceiras (ONGs) para reduzir o desperdício e facilitar o controle de refeições (RSVP) e doações.

🌐 **Acesse o Protótipo Navegável (GitHub Pages):**  
👉 [https://arthurcfn.github.io/projeto---integrador-1-periodo/](https://arthurcfn.github.io/projeto---integrador-1-periodo/)

---

## 📁 Estrutura do Repositório

* **`01-logica-e-algoritmos/`** — Fluxogramas das regras de negócio (coleta de alimentos e controle de estoque).
* **`02-banco-de-dados/`** — Levantamento de requisitos, modelo conceitual (DER) e modelo lógico normalizado.
* **`03-front-end/`** — Protótipo estático responsivo em HTML5 e CSS3, relatório técnico e links do Figma.
* **`04-principios-e-valores/`** — Declaração de propósito, valores éticos e impacto social do projeto.
